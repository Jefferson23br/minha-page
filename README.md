# Currículo PHP - Jefferson Lima

## 📋 Sobre

Esta é uma versão moderna e interativa do currículo em PHP, com design atraente, animações suaves e JavaScript ativo para uma experiência de usuário aprimorada.

## 🚀 Características

- ✅ **Design Moderno**: Interface limpa e profissional com gradientes e animações
- ✅ **Totalmente Responsivo**: Adaptável a todos os dispositivos (mobile, tablet, desktop)
- ✅ **Animações Suaves**: Transições e efeitos visuais em todas as seções
- ✅ **JavaScript Interativo**: Scroll animations, parallax effects, e muito mais
- ✅ **Performance Otimizada**: Lazy loading e throttling para melhor performance
- ✅ **Acessibilidade**: Navegação suave e indicadores visuais

## 📁 Estrutura de Arquivos

```
curriculo-php/
├── index.php              # Arquivo principal PHP
├── assets/
│   ├── css/
│   │   └── style.css      # Estilos modernos com animações
│   ├── js/
│   │   └── script.js      # JavaScript interativo
│   └── images/           # Imagens e logos
└── README.md             # Este arquivo
```

## 🛠️ Tecnologias Utilizadas

- **PHP**: Para renderização dinâmica
- **HTML5**: Estrutura semântica
- **CSS3**: Estilos modernos com animações e gradientes
- **JavaScript (ES6+)**: Interatividade e animações
- **Google Fonts**: Fonte Poppins

## 📦 Instalação

1. Certifique-se de ter um servidor PHP configurado (XAMPP, WAMP, ou servidor de produção)
2. Copie a pasta `curriculo-php` para o diretório do servidor
3. Acesse através do navegador: `http://localhost/curriculo-php/`

## 🔧 Personalização

### Cores
As cores principais podem ser alteradas nas variáveis CSS no início do arquivo `style.css`:

```css
:root {
    --primary-color: #007bff;
    --secondary-color: #28a745;
    --accent-color: #6c63ff;
    /* ... */
}
```

### Conteúdo
Todo o conteúdo está no arquivo `index.php` e pode ser editado diretamente.

## 📝 Notas

- As imagens devem estar na pasta `assets/images/`
- O gráfico do GitHub é carregado dinamicamente via API
- Os badges de tecnologias são carregados do shields.io
